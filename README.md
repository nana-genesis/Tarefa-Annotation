# Tarefa - Annotation @Tabela

Criação de uma anotação personalizada chamada `@Tabela` que recebe o nome da tabela.

## 📚 O que são Annotations?

Annotations (anotações) são "etiquetas" que podem ser colocadas em classes, métodos, campos etc. Elas fornecem metadados sobre o código.

## 🎯 Objetivo da tarefa

Criar uma annotation chamada `@Tabela` que recebe um valor (nome da tabela) e aplicá-la em uma classe de exemplo.
